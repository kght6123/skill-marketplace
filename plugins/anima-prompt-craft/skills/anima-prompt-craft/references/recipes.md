## 1. テンプレA：既存キャラ（タグ主体）

タグ順序どおりに並べる基本形。Base / Turbo 向け。

```
masterpiece, best quality, score_7, newest, highres, safe,
1girl, solo, [character name], [series name], @[artist name],
[表情], [髪], [目], [衣装], [ポーズ・しぐさ], [小物],
[背景], [ライティング], [カメラアングル]
```

- `[character name]` と `[series name]` は Gelbooru 表記に寄せる
- `@` を忘れない。アーティストは1〜2人まで
- タグドロップアウト学習なので、思いつくタグを全部入れなくてよい

## 2. テンプレB：オリジナルキャラ（タグ＋自然文）

Danbooru に存在しないキャラは character / series タグが無い。**一般タグで外見を固定し、自然文1〜2文で補強**する。Anima は自然文が効くので、SDXL 系より寄せやすい。

```
masterpiece, best quality, score_7, newest, highres, safe,
1girl, solo, @[artist name],
[髪色・髪型], [瞳の色・特徴], [肌・表情の特徴],
[衣装], [ポーズ], [背景], [ライティング], [カメラ].
A [雰囲気] girl with [外見の要点] stands in [場所], [動作や光の描写]. [構図や質感の補足を1文].
```

- 自然文は**2文以上**が安定。1文だと弱い
- 外見の要点（髪色・瞳・特徴的なパーツ）は**タグと自然文の両方**に書くと固定されやすい

## 3. テンプレC：非アニメのアート系（データセットタグ）

油彩・デジタルペイント・抽象・イラストレーション寄りを狙うとき。**先頭行にデータセットタグ、改行、任意でタイトル、改行、説明文**。

```
deviantart
[作品タイトル]
[2文以上の英語による具体的な描写。題材・構図・色・質感・スタイル]
```

```
ye-pop
[alt-text 風の短い説明]
[2文以上の英語による具体的な描写]
```

- この形式ではアニメ系のタグ体系を混ぜず、**説明文で押す**のが趣旨
- 写実は出ない（そういうモデル）。狙うのは非写実の絵画・イラスト表現

## 4. テンプレD：Turbo で高速イテレーション

プロンプト詰めの段階は Turbo（CFG 1 / 8〜12ステップ）で回し、決まったら Aesthetic か Base で本番を焼く、という進め方が効率的。

- Turbo は既定の画風が強く多様性が低いので、**構図・被写体の詰め**に向く
- **画風の詰め**は本番バージョンでやり直す必要がある（Turbo で決めた @アーティストの効き方は Base/Aesthetic と一致しない）
- Aesthetic に移す際は **`score_*` タグをポジ・ネガ両方から削る**

## 5. ネガティブの組み立て方

Anima は SDXL 系のような大量固定ネガを必要としない（タグドロップアウト学習＋素体特性）。

**基本（Base / Turbo）**
```
worst quality, low quality, score_1, score_2, score_3, artist name, blurry, jpeg artifacts, chromatic aberration
```

**Aesthetic**
```
worst quality, low quality, artist name, blurry, jpeg artifacts, chromatic aberration
```
※ `score_*` を抜く

**用途別の追加**
- 全年齢を固めたい：`nsfw, explicit`（＋ポジに `safe`）
- 手指・解剖の破綻対策：`bad anatomy, bad hands, extra digits, missing fingers`
- 写実に寄るのを防ぐ：`realistic, photorealistic, 3d`

盛りすぎない。効いていないネガを積むより、ポジの記述を増やす方が効く。

## 6. 症状別トラブルシュート

| 症状 | 原因の見当 | 対処 |
| --- | --- | --- |
| 画風が地味・ニュートラル | Base を素で使っている | `@アーティスト` を入れる／品質タグを入れる／Aesthetic か Turbo に変える |
| @アーティストが効かない | `@` を付け忘れ／マイナーな絵師 | `@` 前置を確認。学習量の少ない絵師は元々弱い |
| 意図しない内容が出る | プロンプトが短い・薄い | ポジに `safe`、ネガに `nsfw, explicit`。衣装・背景・ライティングを具体的に追記 |
| 強調が効かない | SDXL の重み感覚のまま | Anima は高めの重みが必要。`(chibi:2)` 程度まで上げる |
| 複数キャラが混ざる | 名前だけ並べている | 各キャラごとに「名前 → 外見描写」の順で書く |
| 品質が過剰に「盛られた」絵になる | Aesthetic に `score_*` を入れている | `score_*` をポジ・ネガ両方から削除 |
| 写実にならない | 仕様 | 別モデルを使う。Anima は非写実特化 |
| 文字が崩れる | 仕様 | 単語1つ〜短いフレーズに留める |
| 構図が破綻する | 解像度が範囲外 | 512²〜1536² の範囲に収める |
| テクスチャが平坦 | サンプラー / スケジューラ | `beta57` スケジューラ（RES4LYF）を試す。`dpmpp_2m_sde_gpu` で多様性を出す |
| Turbo で焼けた絵になる | CFG が高い | Turbo は **CFG 1**。ステップは 8〜12 |

## 7. SDXL系プロンプトからの移植チェックリスト

Illustrious / NoobAI / Pony 系のプロンプトを Anima に持ってくるとき：

- [ ] アンダースコアをスペースに置換した（`long_hair` → `long hair`）。残すのはスコアタグのみ
- [ ] アーティストタグに `@` を前置した
- [ ] 強調の重みを上げた（SDXL の `1.2` は Anima ではほぼ無効）
- [ ] **SDXL用LoRAを外した**。アーキテクチャが違うので流用不可。使うなら Anima 用 LoRA（高速化したいなら LoRA ではなく Anima-Turbo チェックポイントに切り替える）
- [ ] 巨大な固定ネガを削って、公式推奨ベース＋必要分に絞った
- [ ] タグ順序を公式の並びに直した（品質/メタ/年代/安全 → 1girl 等 → character → series → @artist → 一般）
- [ ] 使うバージョンに合わせて品質タグを調整した（Aesthetic なら `score_*` を削除）
- [ ] ステップ / CFG をバージョンに合わせた（Turbo は 8-12 / CFG 1）
