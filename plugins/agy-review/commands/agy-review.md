`agy` コマンドを使ってコードレビューを実行してください。

## 手順

### 1. レビュー対象ファイルの決定

引数: `$ARGUMENTS`

- 引数が **空** の場合は `git diff --name-only HEAD` と `git diff --name-only --cached` を実行して変更ファイルを取得する
- 引数が **あれば** そのファイルパスをレビュー対象とする

### 2. ファイル内容の読み込み

対象ファイルをすべて Read ツールで読み込む。

### 3. agy プロンプトの構築と実行

以下のレビュープロンプトを `/tmp/agy_review_prompt.txt` に書き出す（Write ツールを使用）:

```
以下のコードをレビューしてください。

観点:
- 型安全性・TypeScriptの使い方（any の乱用・型アサーションの適切さなど）
- 関数・変数・型の命名
- 処理の効率・重複コード
- エラーハンドリング（例外の捕捉・エラーメッセージの品質）
- コメント・ドキュメントの適切さ
- バグ・潜在的な問題
- セキュリティ上の懸念

レビュー結果は問題点と改善提案を箇条書きでまとめてください。深刻度（高/中/低）も付けてください。

=== レビュー対象ファイル ===

{読み込んだ各ファイルのパスと内容をここに展開する}
```

次のコマンドを Bash ツールで実行する（タイムアウト 600000ms = 10分）:

```bash
agy --print "$(cat /tmp/agy_review_prompt.txt)" --print-timeout 10m
```

### 4. 結果の表示

agy の出力をユーザーに提示する。指摘が多い場合は「修正しますか？」と確認する。
